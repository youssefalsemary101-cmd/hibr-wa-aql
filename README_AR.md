# حبر وعقل التعليمية — النسخة التجريبية الثانية

## الملفات
- `index.html`: الهيكل والواجهات.
- `styles.css`: التصميم الكحلي والذهبي ودعم الموبايل والمظهر الداكن.
- `app.js`: تفاعلات العرض التجريبي.
- `manifest.webmanifest` و`sw.js`: إعدادات PWA وتخزين بعض ملفات الواجهة مؤقتًا.

## النشر على GitHub Pages
ارفع **محتويات هذا المجلد** مباشرة إلى جذر المستودع، بحيث يظهر `index.html` في صفحة Code دون فتح مجلد آخر. ثم افتح Settings → Pages، واختر Deploy from a branch، والفرع `main` والمجلد `/(root)`، ثم Save.

## تنبيه أمني مهم
هذه واجهة تجريبية وليست نظام حسابات حقيقيًا:
- لا يوجد خادم أو قاعدة بيانات أو تحقق فعلي من الهاتف.
- كلمة المرور لا تُخزّن ولا تتم المصادقة عليها في خادم.
- اختيار نوع الحساب في الواجهة لا يمنح أمانًا ولا يثبت هوية المستخدم.
- كود المدير التجريبي `HIBA-DEMO` للعرض فقط؛ لا تنشره باعتباره حماية.
- لا تستخدم بيانات حقيقية أو كلمات مرور حقيقية.
- لا بد من خادم موثوق وقاعدة بيانات وقواعد صلاحيات من جهة الخادم لتفعيل حسابات الطلاب والمعلمين والمديرين والرسائل والإحالات ورفع المحتوى بصورة آمنة.

## ملاحظات
محتوى الدروس في هذه النسخة تجريبي ولا يتضمن كتبًا أو ملفات محمية بحقوق نشر. الخط الخارجي يحتاج اتصال إنترنت، وتظل الواجهة الأساسية قابلة للعرض باستخدام خطوط بديلة.
