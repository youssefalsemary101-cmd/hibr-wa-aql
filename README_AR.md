# حبر وعقل التعليمية — نموذج أولي قابل للتجربة

## ما الذي يحتويه هذا الملف؟
- واجهة عربية RTL بألوان كحلي وذهبي، متجاوبة مع الهاتف.
- إنشاء حساب تجريبي برقم هاتف يبدأ بـ 010 أو 011 أو 012، من 11 رقمًا.
- اختيار المرحلة والصف والشعبة/المسار.
- تصفية المحتوى بحيث يرى الطالب محتوى نطاقه الدراسي فقط في واجهة النموذج.
- مواد ومحتوى تجريبي، صفحات معلمين، متابعة، اختبارات بسيطة، بحث، أصدقاء ومجموعات تجريبية.
- لوحة إدارة محلية لإضافة المحتوى وإخفائه وحذفه.
- manifest وservice worker لتجربة PWA عند تشغيلها من استضافة HTTPS.

## تنبيه مهم جدًا
هذا **نموذج أولي تعليمي (Prototype)** وليس منصة إنتاجية آمنة مكتملة. البيانات تُخزن في `localStorage` على الجهاز والمتصفح نفسه. كلمة المرور في النموذج ليست محمية بخادم، والحسابات لا تتزامن بين الأجهزة. لا تستخدم بيانات شخصية حقيقية أو كلمات مرور حقيقية.

الميزات التالية لم تُنفذ إنتاجيًا بعد، وتحتاج خادمًا وقاعدة بيانات ومراجعة أمنية:
- تسجيل دخول حقيقي وتجزئة كلمات المرور واستعادة الحساب وتأكيد ملكية الهاتف.
- أدوار وصلاحيات مدير خادمية وكود سري آمن للمدير.
- تخزين فيديو/PDF حقيقي، رفع آمن، ومراجعة محتوى المعلمين.
- رسائل خاصة ومجموعات متعددة المستخدمين تعمل عبر الإنترنت.
- إشعارات فورية، إبلاغ وحظر خادمي، وسجل تدقيق.
- إحالات ومكافآت موثوقة ومقاومة للتحايل.
- نسخ احتياطي وحذف بيانات وسياسات خصوصية متوافقة مع القوانين.
- دفع واشتراكات مدفوعة.
- دعم دون إنترنت محدود؛ التخزين المؤقت لا يضمن تنزيل كل الدروس.

## طريقة التجربة
1. فك ضغط ZIP في مدير الملفات.
2. افتح `index.html` في متصفح يدعم JavaScript. قد تعمل بعض الوظائف مباشرة، لكن تثبيت PWA وservice worker يتطلبان عادة استضافة HTTPS أو localhost.
3. اختر «إنشاء حساب»، واملأ البيانات. استخدم رقمًا تجريبيًا من 11 رقمًا يبدأ بـ 010 أو 011 أو 012.
4. جرّب المواد والاختبارات والمعلمين والبحث.
5. لوحة الإدارة التجريبية: سجل الدخول بالبيانات الثابتة التالية:
   - الهاتف: `01000000000`
   - كلمة المرور: `AdminDemo123!`
   هذه بيانات تجريبية غير آمنة وليست حسابًا حقيقيًا؛ لا تنشر الموقع مع هذا الدخول كما هو.
6. من لوحة الإدارة أضف محتوى تجريبيًا واربطه بمرحلة وصف وشعبة.

## تشغيل PWA
ارفع الملفات إلى استضافة HTTPS ثابتة. لا ترفع بيانات مستخدمين حقيقية في هذا النموذج. قبل إطلاق عام، استبدل التخزين المحلي بخادم آمن وقاعدة بيانات، وأزل حساب المدير التجريبي.

## هيكل الملفات
- `index.html`: هيكل الواجهات.
- `styles.css`: الألوان والتصميم المتجاوب.
- `app.js`: منطق النموذج التجريبي.
- `manifest.webmanifest`: بيانات تطبيق الويب.
- `sw.js`: التخزين المؤقت الأساسي.
